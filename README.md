# Responsive Landing Page

Projeto desenvolvido com HTML e CSS que cria uma landing page moderna com navegação fixa, imagem de fundo, textos de destaque e botões de ação. O layout foi construído com foco em apresentação visual e experiência do usuário.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts (Poppins)

## ✨ Funcionalidades

- Navbar fixa
- Hero Section
- Imagem de fundo
- Overlay escurecido
- Botões de ação
- Layout responsivo
- Design moderno
- Navegação intuitiva

## 🎯 Como Executar

1. Clone ou baixe o projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
